# 1c-fixtures

Открытая конфигурация Coverage и фикстуры для проверки инструментов 1С.
Корпус включает исходные шаблоны, отдельные варианты, общие конфигурации,
штатные XML/CF/CFE/EPF/ERF и минимальные обезличенные legacy-примеры.

- `coverage/` — наборы по точным версиям платформы, включая `combined`.
- `coverage-records/` — минимальные записи, XML-пробы и признаки сохранности.
- `tools/coverage/` — генерация вариантов и доказательство штатного round-trip.
- `corpus-index.json` — полный перечень файлов корпуса с SHA-256.
- `provenance/ibcmd-rs-export.json` — исходный коммит и учёт каждого перенесённого файла.

```text
python tools/verify_corpus.py
python -m unittest discover -s tools/coverage -p test_*.py
python tools/coverage/generate.py coverage/<platform>/<set> <scratch/tree>
python tools/coverage/native_round_trip.py --help
python tools/coverage/combine.py --help
```

Для проверки готового корпуса 1С не нужна. Для изменения штатных эталонов нужна
соответствующая установленная платформа и два совпадающих штатных круга.
После такого изменения обновите индекс `python tools/verify_corpus.py --write-index`.
Эта команда не исправляет и не перезаписывает штатные манифесты.

Потребитель подключает конкретный коммит корпуса. Baseline и ожидания ошибок
конкретного конвертера хранятся у потребителя, в частности в ibcmd-rs.
Обновление корпуса само по себе не отменяет ни одного обещания равенства.

Прикладные конфигурации и их данные в корпус не включены. Исходные материалы
извлечены из ibcmd-rs, происхождение и сохранность отражены в `provenance/`.
